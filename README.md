# GeminiDoc-Insights

A Google Colab notebook demonstrating how to extract insights from YouTube video transcripts and PDF documents using the Google Gemini API.

## Features

* **Insight Extraction:** Analyzes data from both YouTube video transcripts and PDF documents.
* **Google Gemini API:** Leverages advanced LLM capabilities to parse and understand content.
* **Langchain Integration:** Features efficient text chunking for optimal processing of large documents.
